# 【阶段 0：赛题精读与范围界定】

本次交付是后续建模共同使用的问题定义。核心任务是在保障小区用电、满足储能运行约束的条件下，制定日前购电计划及允许的日内调整，使总购电费用尽可能低。题型为带预测信息的动态优化与决策问题；预测服务于购电决策，不能只报告预测精度而不回答购电与储能策略。

本报告依据项目提供的C题.pdf全部3页、上阶段实际读取的附件元信息及协作提示词。题目要求、可复核的算术推导、拟采用的建模假设分别标明。没有执行数据清洗、预测训练或优化求解，也没有生成最终结果表。

## 2. 时间边界与单位

### 2.1 主线采用的自然日解释

**题目事实：** 原始数据每天144个时点，从0:10到0:00+1；题目要求以0:00制定当天计划，并输出10分钟区间电量及0:00、24:00储电量。模板计划区间整体从0:10起，末段延伸至次日；年度模板末段文字还存在不同写法。

**拟采用的解释A：** 每个原始时点代表此前一个10分钟区间的功率或价格，以该区间的代表值进行离散计算。这使完整一天覆盖0:00—24:00。该解释属于离散化假设，题目没有明确说这些功率是区间均值；不能把右端点代表值等同于已证实的区间均值。

设第d日第t段为

\[
I_{d,t}=[d+(t-1)\Delta t,\ d+t\Delta t),\qquad
\Delta t=\frac16\ \mathrm{h},\quad t=1,\ldots,144.
\]

程序内部采用严格递增的时间戳和区间编号，不能使用模板字符串作为唯一计算索引。

| 原始数据标签 | 内部标准区间 | 用途或注意点 |
| --- | --- | --- |
| 0:10 | 0:00—0:10，第1段 | 对应自然日第一段 |
| 10:10 | 10:00—10:10，第61段 | 对应论文表1的10:00指定区间 |
| 12:10 | 12:00—12:10，第73段 | 同上 |
| 14:10 | 14:00—14:10，第85段 | 同上 |
| 16:10 | 16:00—16:10，第97段 | 同上 |
| 18:10 | 18:00—18:10，第109段 | 同上 |
| 20:10 | 20:00—20:10，第121段 | 同上 |
| 0:00+1 | 23:50—24:00，第144段 | 储能更新后得到当日24:00状态 |

**保留的解释B：** 若标签代表随后区间，时域就是0:10至次日0:10，需要补足自然日0:00段并说明跨日取值；若标签代表瞬时采样，也可以研究积分近似，但必须明确边界点来源。不得把一天内循环平移当成已经验证正确的修复。

**模板输出约定：** 内部主线按解释A计算。后续结果导出以自然日区间形成标签修订和映射记录；保留原始模板，不能将计算对应的区间与显示标签错配。最终填写前再核对有无官方勘误。本轮只登记拟采用方案，不修改原始模板，也不声称官方已确认其笔误。

### 2.2 功率与电量

功率输入单位kW，电量输出单位kWh，价格单位元/kWh，费用单位元。若区间代表功率为P，则区间电量为P/6；每日电量是144段电量之和，不能直接将144个功率数值相加作为kWh。

由5000 kW功率限制和10分钟长度推得，单段充电或放电电量上界为5000/6≈833.333333 kWh。此数值是参数推导，不是求解结果。每个4小时统计区间包含24个10分钟段。

## 3. 决策时点能够知道什么

### 3.1 信息约束

**主线建模假设：** 每次决策只使用当时已发布的预报、已经发生的观测，以及当前储电量。决策不访问未来真实负载、未来真实光伏或尚未实现的波动电价。题目并未完整规定数据到达时刻，故此处是为形成可运行策略所采用的信息假设。

以\(\mathcal F_\tau\)表示在决策时刻\(\tau\)可使用的信息，日前计划及日内修订必须分别由当时的信息决定。程序应同时记录预报发布时间和目标时间，防止预测目标的实际值混入输入。

| 信息 | 问题1 | 问题2与4-2 | 问题3与4-3 |
| --- | --- | --- | --- |
| 附件1整日电价 | 已知 | 问题2使用；4-2由附件4价格环境替代 | 问题3使用；4-3由附件4价格环境替代 |
| 附件1负载及光伏预测 | 给定规划输入 | 不沿用为全年当天真实值 | 不沿用为全年当天真实值 |
| 附件2的过去观测 | 不需要 | 可使用截至决策时刻的历史 | 可使用截至决策时刻的历史 |
| 附件2的未来实际值 | 不涉及实际回测数据 | 仅用于后续回测检验 | 仅用于后续回测检验 |
| 附件3光伏预报 | 不使用 | 不使用，保持问题2信息条件 | 只使用发布时间不晚于当前时刻的版本 |
| 附件4波动价格 | 不使用 | 4-2使用过去价格预测未来价格；实际价格用于结算 | 4-3同左，可在调整时利用新近观测 |
| 当前储能状态 | 单日初始值 | 承接历史实际运行状态 | 承接历史实际运行状态 |

实时补缺允许根据当前时段实际供需和电池可用状态执行；这是10分钟离散实时平衡近似，不意味着0:00能知道当日全部时段结果。具体时段内测量和控制先后关系需在求解实现中一致表达。

若另计算全天真实值已知的方案，应明确命名为完全信息对照。在物理约束、结算、时域和边界一致时，信息放宽后的全局最优费用可作为理论下界；不能将不同条件下的一次启发式求解费用称为严格下界。

### 3.2 小时预报的目标时刻

题目给出的预报是发布后未来24小时整点的光伏功率。假设在第d日6:00发布，则“预报1小时”指向当日7:00，“预报24小时”指向次日6:00。18:00版本的“预报7小时”已经指向次日1:00。日期列的延续空字符串须先恢复所属发布日期，再构造绝对目标时间。

小时预报转成10分钟输入需要插值或分段近似，这属于后续预处理选择。处理第一个预报小时的左边界时，只能取决策时点已知的观测或已经发布的预测，不能用未来实际光伏补齐。即使预报包含次日信息，已执行时段也不能被重新修改。

以下用于统一记账，不是本轮已经构建和求解的完整优化模型。

| 量 | 主线口径 | 证据等级 |
| --- | --- | --- |
| 额定容量 | 12000 kWh | 题目附录1 |
| 可运行储电范围 | 1200—10800 kWh | 题目附录1；不能把12000作为日常运行上限 |
| 初始储电量 | 2025-01-01 0:00为6000 kWh | 题目附录1 |
| 充放电功率限制 | 各5000 kW，主线解释为微网母线侧功率限制 | 数值来自题目，测量侧为假设 |
| 充电量c、放电量b | 均以微网母线侧电量记账，单位kWh | 建模口径 |
| 效率 | 主线\(\eta_c=\eta_d=0.9\) | 将“充放电效率90%”解释为单向效率，属于假设 |
| 储能状态E | 电池内部储电量，单位kWh | 建模口径 |

相邻时段应满足同一套记账关系：

\[
E_t=E_{t-1}+\eta_c c_t-\frac{b_t}{\eta_d},\qquad
1200\le E_t\le10800.
\]

单向均为90%时，往返效率为81%。保留往返效率为90%的替代解释，此时对称单向效率取\(\sqrt{0.9}\approx0.948683\)。两种定义不能同时使用；后续如做敏感性验证，应重新求解并以同一统计口径比较。

**其余主线假设：** 不向外网售电，因为题目未给售电规则；可无收益处置无法消纳的余电，作为供电不低于负载条件中的非负余量，且处置量应记录；不允许电池在同一时段同时充放电；暂不加入未给定的自放电、设备折旧、需量电费、线路损耗或电网购电功率上限。禁止同时充放电的实现方式在模型设计阶段确定，不先假定任何优化器会自动满足。

问题1必须满足日初日末储电量相等，主线取6000 kWh为该日初值。问题2—4只明确给了1月1日初始值，并没有重复规定每天恢复6000 kWh，因此不能把逐日归零式重置作为题目事实。

年度运行主线承接实际状态：\(E_{d+1,0}=E_{d,144}\)。1月需要形成可说明、可复现的运行或初始化过程，其末值作为2月1日初值；不能用1月训练完模型后，再把该模型回填到尚未获得这些数据的1月决策中。缺少1月之前数据时，预热期控制及起始预测规则在阶段1单独确定。

同口径策略比较宜共用2月1日初始状态，并披露年末状态；是否使用终端等式、终端能量价值或其他边界控制在模型设计阶段选择。终端约束属于防止边界效应的建模安排，不是问题2—4已经给出的硬性条件。

## 5. 费用结算需要保留的两个解释

设某段日前计划购电量为q，日内最终调整后的计划总量为a，实际额外紧急购电量为e，三者单位均为kWh。a表示调整后的总量，不是增减量；增减量另外记录为a−q。记\((x)_+=\max(x,0)\)。

固定电价情形用p表示该交付时段价格；问题2没有日内计划调整，故a=q。该段费用按题目直接记为：

\[
K_2=pq+5pe.
\]

光伏、计划供电和电池放电满足负载、充电及允许处置的余量；紧急购电只补上经过允许调度后仍存在的缺口。紧急购电不能被再次计入计划量q而重复收费。

### 5.1 解释A：取消电量退回原价，另收50%违约费用

**这是拟用于比较的建模解释，不是题目已经说明的退款规则。** 设取消部分不再按原价支付，则：

\[
\begin{aligned}
K_{3,A}
&=p\min(q,a)+0.5p(q-a)_++1.5p(a-q)_++5pe\\
&=pq-0.5p(q-a)_++1.5p(a-q)_++5pe.
\end{aligned}
\]

第一行区分保留原计划部分、取消部分违约费和追加部分费用；第二行以原计划费用为起点表达净变动。不能在退款后的式子上再额外重复计一遍全部原计划费用。

### 5.2 解释B：原计划全部付费，减少部分再付50%违约费用

如果严格按原计划全部付费且不退回取消部分，则：

\[
K_{3,B}=pq+0.5p(q-a)_++1.5p(a-q)_++5pe.
\]

两种解释在a≥q时一致，在a<q时相差\(p(q-a)\)。这属于制度口径差异，不能通过调整预测模型代替说明。

在p>0、余电可免费处置、没有额外接收限制的前提下，解释B下为了应对余电而主动减购一般被“保留原计划并处置余电”支配：前者多付违约费，却没有退款。这个推论不表示所有日内预报都无价值，追加购电以及根据新信息调整储能仍可能减少紧急购电。若价格为负或余电不能处置，该支配判断需要重新检查。

**后续处理约定：** 保留A/B两套结算选项。先核对有无官方补充解释；无补充时，以A作为可取消合同假设的主线候选，同时必须报告B的对照或在定稿中明确选择理由。不能把A写成“题目规定”，也不能只给读者看费用更低的一种。

上述公式描述固定电价下单个时段的结算关系，并非数值结果。此阶段不报告哪种策略节约多少费用。

### 5.3 多次调整与波动电价

题目没有明确6:00、12:00、18:00的每次修改是否分别收费。拟采用的简化是假定尚未交付的计划可以更新，按最终交付时段的有效调整总量a与0:00原计划q之差结算一次；全部发布版本和修改记录需保存以供复查。若实际规则按每次交易收费，则应累计每次增减量，不能继续使用最终净差掩盖往返修改成本。两者不能混算。

问题4还需界定“交易时刻”是计划下单、日内修改还是电量交付时点。附件4只有一套每日10分钟电价序列，没有分别给出日前与日内不同市场的报价。主线候选按交付时段的实际价格\(p_{d,t}\)统一结算该段计划、调整及紧急购电；提前决策使用当时对该价格的预测。该统一价格假设必须在论文中披露。若改用下单时价格，须重新定义各费用项，不得把下单时刻价格和交付时段价格任意混用。

## 6. 评价范围与完整回答的判据

**时间范围：** 原始材料为2025年全年；年度结果提交范围为2月1日至12月31日，共334天、每个年度方案48096个10分钟区间。1月用于历史准备及初始状态衔接，其费用不并入2—12月主结果，除非单独标注为额外统计。

**最低完整性要求：** 五个工作簿逐问输出；年度计划保存每日0:00当时制定的原计划，不用后来的修订覆盖；日内调整保存各区间交付前最终有效的总量，同时在支撑材料保存完整版本记录；储能表填写实际执行的充放电量和日初日末状态；紧急购电表按日归并连续发生区间，保留10分钟明细，跨日分开统计。

题目表1中的“全天购电量”在含调整、紧急购电的问题中存在统计口径空间。内部必须同时保留原计划总量\(\sum q\)、调整后常规购电量\(\sum a\)、紧急购电量\(\sum e\)和实际外网购电总量\(\sum(a+e)\)。计划工作表的“全天购电量”建议与其144段计划单元格之和一致；论文表1建议注明常规和紧急电量并报告实际总量。“全天购电费”应披露是否为含紧急与调整费用的总费用，并用独立费用分解复核。最终表格需明确表注，不能让相同字段暗中代表不同口径。

指定展示日期为2025-03-20、06-21、09-23、12-21；全年评价不能只根据这四天选模型。问题3及4-3必须至少能分开回答：

1. 在同样已经拥有0:00预报时，新增6:00、12:00、18:00版本，是否降低含调整费在内的总费用？
2. 各次预报分别带来什么边际价值？是否存在不值得调整的时段？
3. 改善来自更少的紧急购电还是储能调度变化，其代价是什么？
