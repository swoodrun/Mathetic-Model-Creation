## 4. 共用物理与费用模型

每段满足

\[
a_t+r_t+d_t+h_t=l_t+c_t+w_t,\qquad
E_t=E_{t-1}+\eta_c c_t-d_t/\eta_d,
\]

\[
1200\le E_t\le10800,\quad 0\le c_t,d_t\le M,\quad
a_t,g_t,h_t,w_t\ge0,\quad c_td_t=0.
\]

Q1：h=0、a=g、E0=E144=6000，min Σp_tg_t。无储能基线为g_t=max(l_t−r_t,0)，其全天成本是本题口径下的比较基线。

Q2：K_t=p_tg_t+5p_th_t。

Q3及Q4-3：

\[
K_t^B=p_tg_t+0.5p_t(g_t-a_t)_++1.5p_t(a_t-g_t)_++5p_th_t,
\]
\[
K_t^A=p_tg_t-0.5p_t(g_t-a_t)_++1.5p_t(a_t-g_t)_++5p_th_t.
\]

常规费用记F(g,a,p)=K−5ph。p>0且g固定时，B可用u≥1.5pg−0.5pa及u≥1.5pa−0.5pg表示；A用u≥0.5p(g+a)及u≥1.5pa−0.5pg表示。最小化u得到相应凸分段费用，分段本身不需要二元变量。Q4必须给场景价格下的pg也计价；不能把不确定价格只作用于应急费。

B下a<g被a=g且多余电量免费处置支配。因此B分支的新计划可加a≥g缩小搜索域；这不表示a必须比上一个版本更大：上一版本曾买多后，可以回落到g以上。保留原始g，不将上次a误作新g。

若采用逐次交易合同，另定义a⁽⁰⁾=g及各次增量Δa=a⁽ʲ⁾−a⁽ʲ⁻¹⁾，常规费为pg+Σ[1.5p(Δa)+ +b−p(−Δa)+]，b−在B/A分别为0.5/−0.5；只对尚未交付段收费。此分支是另一合同假设，不将各次完整F相加。首轮实现净差结算，逐次分支列为可选敏感性。

### LP充放电互斥的有效条件

令rη=ηcηd，δ=min(c,d/rη)，将c改为c−δ、d改为d−rηδ、w改为w+(1−rη)δ。购电与E均不变、c或d至少一项归零、上下界不恶化，费用不变。这证明在本模型的无约束免费处置条件下可从LP解恢复互斥解，不能推广到限制w或包含其他耦合费用的模型。

阶段4先对Q1运行LP与MILP并核对目标值和物理残差。MILP采用c≤Mz、d≤M(1−z)，z∈{0,1}；不使用任意巨大M。

## 5. 预测、残差档案与场景

### 5.1 首轮固定预测器

负载主预测采用过去28个完整运行日中与目标日同星期、同slot的均值；无同星期样本时退为过去最多7个完整日同slot均值。备选为昨日值，以及用过去历史识别高低负载日的分组模型。不能照搬传统工作日/周末二分。首轮固定28日同星期主线，不用全年结果挑选预测器后再称其样本外最优。

Q2/4-2光伏使用过去最多7个完整日同slot算术均值。Q3/4-3使用当前已发布版本的pv_linear_kwh，只取当天剩余段。2B分段常数映射为敏感性对照。原始预报档案中的h=0锚点已通过复核，不二次插入未来实测值。

价格主预测为过去最多7个完整日同slot的几何均值，即exp(mean(log p))，保持正值。这是点预测中心，不称为条件期望。算术均值价格是备选。Q4-3首轮在同一天固定该价格中心，日内只更新PV、当前SOC和剩余时域；这样可先辨认PV更新的作用。使用当日已实现价格更新中心是后续独立增量，不混入首轮PV信息价值对照。

同理首轮负载预测在当天固定，τ更新PV和电池状态。该限制降低自由度，但舍弃了部分当天负载信息；如基线误差明显，可追加基于已发生负载的因果校准，需另存预测器ID和消融结果。

### 5.2 误差的方向及历史可用性

统一模型残差为实际减预测：eL=l−l̂、eR=r−r̂；价格残差为eP=log p−log p̂。2B误差表是预测减实际，若读取它构造PV残差，必须取负并将kW除以6。不可原符号相加。

每个历史预测均在它当时的截止条件下生成，档案记录predictor_id、issue、训练日集合、prediction、target及target_available_at。Q2、Q3不同PV信息来源分别建档，不混用；不同备选预测器亦有独立档案。

首日无历史时不伪造训练数据。Jan1按共同预热运行，不形成主预测器误差样本；Jan2起可使用Jan1数据产生历史预测，完整误差到Jan3 00时才入池。Feb1首轮最多可拥有Jan2—31共30条日路径；实际数量由实现逐条核验，不硬编码30条必然可用。

每次决策最多取最近30个合格历史运行日。Q3只选同发布小时的历史版本，截取各自发布后至当天24时的残差，与当前剩余slot对齐。路径必须整体实现；至少要求历史运行日结束时刻≤τ。相同s的eL、eR、eP来自同一个历史日与相同目标slot。光伏0/6/12/18版本不得按目标时间用最终版本覆盖旧版本。

### 5.3 当前场景构造

\[
l_{t,s}=\max(0,\hat l_t+e^L_{t,s}),\qquad
r_{t,s}=\max(0,\hat r_t+e^R_{t,s}),\qquad
p_{t,s}=\exp(\log\hat p_t+e^P_{t,s}).
\]

Q2/3直接用给定固定p。该构造保留历史日内及跨变量配对，对数变换使Q4场景价格正值；不是假设残差正态。裁剪负负载/光伏是场景物理投影，不修改原始数据；记录裁剪条数与电量比例，超过预先设定的诊断比例需检查场景失配，不能静默处理。价格exp出现溢出/非有限值即拒绝该场景并记录，不靠任意价格上限掩盖问题。

不利用全年零值分布硬设夜间掩码，不设未经题目支持的装机容量上限。若出现非物理夜间PV场景，先报告来源与频度，再在仅过去数据支持下设计替代残差模型，不能据全年数据反向修补历史。

等权ωs=1/S。S=0时退回点预测方案，取无裕量、b=0；1≤S<20时只做风险中性评分，CVaR主对照要求S≥20。这些是首轮工程阈值，不是统计可靠性的保证。最多30日样本下90%尾部只有约3日信息，日内21万条多版本记录不能充当独立样本量。

## 6. LP候选与同一套反馈执行

对投影后的场景，计算净负载偏差ξt,s=(lt,s−rt,s)−N̂t。保留未经修正的N̂，并用α∈{0.5,0.8,0.9}构造Ñt=N̂t+max(0,Qα(ξt,·))。分位数固定采用线性插值法；重复净负载向量按容差去重。裕量单位为kWh，不对负载和PV各自独立取高分位再拼接。

### 6.1 参考轨迹LP

年度每个候选以当前真实E为起点，最小化

\[
\sum_{t\in T_\tau}\big[F_t(a_t)+5\hat p_t v_t\big]+\kappa_D u_E,
\quad u_E\ge E_T-6000,\quad u_E\ge6000-E_T,
\]

约束为a+d+v=Ñ+c+w、SOC递推与物理边界。0时令a=g、F= p̂a，允许自由选常规购电；Q3日内固定原g，F为对应A/B结算；Q2无日内改购。问题1用真实给定净负载，v=0及硬终端等式，取代软目标。

κD=ηd×当天0时可获得的全日价格中心中位数，日内保持不变；敏感性取0、1、2倍。它只是末态机会价值近似，不是题目收费。

**保留计划时**固定a为当前剩余计划，仍可重算参考E*。因为固定a可能无法满足预测净负载，所以允许v≥0并按5p̂惩罚，确保参考LP不因预测缺额不可行。v是生成参考用的辅助量；实际h由下面控制器重新计算，不能把v作为结果导出。原计划不变且原参考未重算的现行策略也保留为候选，防止新参考反而更差。

0时至多4份LP计划，每份配b∈{0,600}形成至多8个候选。日内修改与固定a的参考重规划各至多4份×2个b，另加1份现行策略，至多17个候选，随后去重。这比旧总体方案笼统的“最多8个”补齐了保留计划一侧的计算量。

### 6.2 真实与场景共用反馈规则

定义m=a+r−l，R=clip(E*段末−b,Emin,Emax)。

- m≥0：c=min(m,M,(Emax−Eprev)/ηc)，d=h=0，w=m−c。
- m<0：d=min(−m,M,ηd max(Eprev−R,0))，c=w=0，h=−m−d。
- 用实际c、d更新E；不得把参考E*赋给真实E。

控制器参数在决策时已固定，每段仅读取本段供需、当前E及预先确定的参考。它不根据场景后面的真实路径重新规划；紧急电只补负载缺额，不主动充电。保留较高R可能导致电池尚有电却应急购电，费用必须如实计入。

该规则是明确的可行策略类，未证明在所有随机情形最优。候选LP本身可精确求解，不代表“候选生成＋反馈择优”也是完整随机控制全局最优。

## 7. 风险评分与滚动触发

对候选i，逐场景回放得到剩余时域完整结算费用Ci,s及实际末态Ei,T,s。定义

\[
\operatorname{CVaR}_\beta(C_i)=\min_z\left[z+\frac{\sum_s\omega_s(C_{i,s}-z)_+}{1-\beta}\right],
\]
\[
J_i=\sum_s\omega_sC_{i,s}+\lambda\operatorname{CVaR}_\beta(C_i)
+\kappa_D\sum_s\omega_s|E_{i,T,s}-6000|.
\]

主线λ=0，固定增强λ=0.1、0.3，β=0.9。比较版本分别连续运行，首轮不通过2—12月最低费用事后挑λ并称其事先选定。正λ强调尾部费用，可能提高均值；论文必须同时列原费用和风险变化。CVaR采用离散质量下的上式或等价分数尾部加权，不能简单平均“严格大于分位数”的样本而丢掉分位点质量。方法依据[Rockafellar与Uryasev原始研究](https://sites.math.washington.edu/~rtr/papers/rtr179-CVaR1.pdf)，本题应用及信息约束由本设计给定。

日内已经实际支付的费用是所有候选相同的确定常数，可统一从剩余评分中删去。但未来原计划pg在Q4场景下是随机量，虽对同场景各候选相同，仍不可随意从CVaR中删去：随机共项会改变尾部排序。

在Q3各发布时刻，用相同当前SOC、场景、κ和λ计算最好的保留计划分数Jkeep和改购分数Jchange，仅ΔJ=Jkeep−Jchange>ε时改购；否则选最好的keep参考策略。ε=0为主线，10元为固定正阈值敏感性，属于忽略小预测收益的工程选择，不是交易费；不在实际电费中加ε，也不再重复加违约费。分数在1e−6元内相同时优先不改购，再按候选ID确定，保证复现。

每次评分假定之后不再收到新预报，真实下一发布到来时再重算，属于滚动近似。已交付时段的计划、动作和费用冻结；首版不承诺跨日预报对应的次日购电。

简化解释：无储能且D非负、p>0，min pq+5p E[(D−q)+]给出连续分布临界F(q)=0.8；缺购边际成本为4p、多购为p。此前83.3%把增量成本算错。该推导只解释不对称成本方向，不把0.8当作储能系统的理论最优分位数。

## 8. 共同预热、年度回放与验证实验

Jan1从6000开始，g=0；Jan2—31令g为昨日逐slot正净负载。每段余量尽可能充电，缺口在边界内尽可能放电并应急补足，即前述控制器R=Emin。此预热策略与价格无关，费用可按各题价格分别记账，SOC轨迹共同。1月费用独立报告；Feb1状态来自实际回放，随后各策略独立连续运行，不重置SOC。

无储能年度对照没有电池状态；其他储能策略比较使用同一初态。Q1是独立代表日问题，仍用6000首末态。实际年末库存不同必须报告；κ=0/1/2倍敏感性需分别完整回放，不能靠最后强行改E使其相同。若需要严格同终端比较，另运行明确终端条件的比较实验，不能把未实际发生的库存修正称为支付电费。

| 编号 | 比较对象 | 固定条件与需要回答的问题 |
|---|---|---|
| E01 | Q1无储能、LP、MILP及两效率 | 核对可行性和储能节费，LP/MILP目标差 |
| E02 | Q2无裕量、固定裕量、λ=0场景选择 | 同预测与反馈。固定裕量为前7个完整日正净负载同slot均值的10%，首轮预先固定；比较实际总费与应急量 |
| E03 | Q2 λ=0、0.1、0.3 | 同候选和场景；报告风险收益，不强求CVaR均值更低 |
| E04 | Q3零时策略、仅更新参考但a不变、允许改购 | 6/12/18状态观测相同；分离参考重规划和交易调整作用 |
| E05 | Q3启用{0}、{0,6}、{0,6,12}、{0,6,12,18} | 各自完整年度连续运行；VOI=基准总费−增强总费，可负；累加顺序不是独立因果贡献 |
| E06 | ε=0与10元；必要时移除单个发布版本 | 相同场景及风险权重；量化交易改变次数与费用，不编造每小时新预报 |
| E07 | Q4点价格场景、联合价格场景、打乱价格对应 | 负载PV路径配对保持不变；对价格整日路径做固定seed=2026的排列，保持价格边际路径，破坏跨变量配对；固定同一价格中心及候选生成规则 |
| E08 | Q4仅价格提前已知 | 负载PV仍按原信息，明确为不可实施的信息对照，不冒称全信息最优下界 |
| E09 | A/B、κ及效率敏感性 | 各配置重新择优并回放，不只替换最终费率；逐次交易为后续可选 |

E04的三条策略均进行10分钟物理执行；零时策略不在日内改参考，第二条每次用最新已授权PV及状态但固定a，第三条允许交易。E05相同发布集合之外不使用新版本更新参考，避免把额外信息偷偷留在基线里。

E02无裕量与固定裕量均固定b=0；λ版本之间使用相同b候选集。应急次数同时保存“非零10分钟段数”和“连续应急事件数”，同日相邻非零段合并、跨日分开，避免口径混淆。

主指标：334日实际总费用、应急电量/次数/发生天数、应急费用、上调费用、下调净费用、未消纳余电、年末E、逐日经验CVaR90/95。常规计划量Σg、实际常规量Σa及实际外网总量Σ(a+h)分别报告。风险目标J与末态软惩罚分列，不伪装成电费。

记录同日基线差、分月结果和最坏日，避免把季节性高需求全解释为决策失败。四个指定展示日不能替代全年验证。若可选模型要自动调参，须新增并预先固定历史滚动验证规则；首轮固定参数，不额外打开事后调参通道。

## 9. 阶段4模块接口与验收门槛

| 模块 | 输入→输出 | 强制约束 |
|---|---|---|
| ObservationView | actual库、as_of→历史观测 | 仅available_at≤as_of；预测器不得持有完整真实未来表 |
| ForecastArchive | 预测器ID、生成时点→预测及来源 | 每个历史预测按当时历史生成，未来补算不得换成全样本拟合 |
| ScenarioBuilder | 已实现残差、当前预测→S×H路径 | 完整路径截止、相同历史日配对、符号和单位、投影日志 |
| CandidateLP | 状态、净负载中心、价格、合同、可改标志→计划/参考 | Q1硬终端；年度软终端；keep固定a，允许v |
| DispatchStep | 当前实际l/r、a、Eprev、E*、b→c/d/h/w/E | 不读取未来；场景和实际共用同一函数 |
| Settlement | 原g、交付前最终a、h、实际p→费用分项 | 只结算一次；原g不可覆盖；风险项不入账 |
| RollingPolicy | τ历史快照、当前状态→候选ID/版本 | 只能在授权发布时刻改购，已发生部分冻结 |
| Export | 实际回放台账→五份结果及论文表 | 334日全覆盖，连续应急段合并，能源与费用可逐段回溯 |

日志最少包含运行ID/配置摘要、预测生成与训练截止、历史样本日、每个候选场景费和J、ΔJ、原g、各版本a、交付版本、Eprev/c/d/h/w/E及所有费用分项。结果模板显示日费的约定：计划表Σpg；调整表ΣF(g,a,p)；含应急实际总费ΣK另列台账和论文表。此为字段工作解释，最终导出说明中披露，不能把两列相加重复计费。

实施顺序：环境与公式检查→Q1 LP/MILP→预测档案和共同预热→Q2一天/一周→Q2全年→Q3→Q4→对照与五表导出。先测实际耗时再估算全量，不能将候选数量估计写成已测运行时间。

验收项：最大能量平衡及SOC递推残差≤1e−6 kWh、SOC/功率边界误差≤1e−6、互斥min(c,d)≤1e−6、费用重算绝对误差≤1e−4元或相对≤1e−10；Q1硬末态与年度跨日连续分别检查。优化器状态不可行/无界/超时不得写成最优；若残差超限，检查缩放与求解状态，不直接放宽容差掩盖错误。

因果测试：改变τ之后实际数据，应不改变τ时预测、计划及候选；保持某段以前信息不变只改更晚场景尾部，已固定控制器此前动作应一致。后者固定候选再测，不能要求事前使用全场景评分选出的候选也对场景尾部不敏感。

预期每次LP变量/约束随H线性增长；场景执行约O(候选数×S×H)，时间必须顺序递推，场景维可向量化。累计实际求解耗时、失败原因及MIP间隙。采用[SciPy linprog](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linprog.html)和[SciPy milp](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html)接口；本轮仅核查官方文档，未安装求解器或宣称已求解赛题。
